# NMDC Runtime

The NMDC Runtime is a metadata management and workflow orchestration system designed by the [National Microbiome Data Collaborative](https://microbiomedata.org/).

Microbiome researchers, data scientists, and bioinformaticians use it to:

- Retrieve and manage metadata
- Mint and manage persistent identifiers
- Manage workflows and their execution

## Usage

**First time here?**
You can access tutorials, how-to guides, references, and explanations related to the NMDC Runtime,
by visiting the **NMDC Runtime Documentation** website at
[`docs.microbiomedata.org/runtime`](https://docs.microbiomedata.org/runtime/).

**Ready to go?**
The NMDC Runtime has an HTTP API.
You can access its interactive documentation (i.e. **Swagger UI**) at
[`api.microbiomedata.org/docs`](https://api.microbiomedata.org/docs).
